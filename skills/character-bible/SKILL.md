# Character Bible

## Overview
Create consistent character definitions and prompt snippets that can be reused across scenes and shots.

## Workflow

1. **Extract characters**
   - Pull names, roles, relationships, and distinctive traits from the story outline.

2. **Define visual profile**
   - Age range, build, wardrobe, signature props, color palette.

3. **Define behavior and voice**
   - Speaking style, cadence, emotional range.

4. **Create prompt snippets**
   - Provide a compact snippet per character for reuse in prompt-pack.

5. **Continuity notes**
   - Track rules (e.g., same jacket, consistent hairstyle, recurring prop).

## Output Guidance

- Keep prompt snippets under 2 lines.
- Use stable descriptors and avoid time-specific props unless required.
- Include a short "do not change" list.
